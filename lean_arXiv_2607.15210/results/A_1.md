# Lemma A.1: Bernoulli free-convolution spectral edge

Complete.

The rightmost topological support point of an actual compact probability measure with the standard additive Bernoulli R-transform germ equals the stated constrained maximum. The actual Cauchy transform, branch continuation, holomorphic inverse obstruction, and finite/infinite endpoint alternatives are proved.
